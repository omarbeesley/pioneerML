# ML-background pedagogical figures

Figures for the machine-learning background section. Each is generated by a
standalone script that imports the shared style module `figstyle.py`, and is
saved as both a vector `.pdf` (for `\includegraphics`) and a `.png` (for review).

Render (all five):
```bash
source /home/obeesley/miniconda3/etc/profile.d/conda.sh && conda activate research
cd figures/ml_pedagogy
python fig_linear_regression_gd.py    # gradient descent -> line of best fit
python fig_embedding_separability.py  # 2D circle -> 3D lift, separating plane
python fig_activation_functions.py    # ReLU / GELU / sigmoid
python fig_attention_affinity.py      # worked example of the attention operation (QK -> softmax -> AV)
python fig_gradient_stability.py      # exploding / vanishing / stabilized gradients
```

The first three cover the explicit pedagogical examples (iterative linear
regression, the embedding example, the activation-function `Figure~\ref{}`). The
last two are the two additional data plots the section's prose implies: the
attention mechanism and the exploding/vanishing-gradient problem. The transformer
block (5-step recipe) and GNN message passing are better drawn as TikZ schematics
and are not produced here.

No system LaTeX is required: equations are drawn with matplotlib mathtext
(Computer-Modern math + serif text). Palette matches the house analysis colours
(red `#d62728`, blue `#1f77b4`, green `#2ca02c`).

## LaTeX inclusion

```latex
\begin{figure}[htbp]
    \centering
    \includegraphics[width=\textwidth]{figures/ml_pedagogy/fig_linear_regression_gd.pdf}
    \caption{Linear regression solved by gradient descent. (a) Forty points
    scattered about a line are fit by $y = wx + b$; the coloured lines show the
    model at successive training iterations, from a poor random start to the
    converged fit, which coincides with the closed-form least-squares line
    (dashed). (b) The mean-squared-error loss falls monotonically as training
    proceeds; the marked points correspond to the iterations drawn in (a).}
    \label{fig:linear-regression-gd}
\end{figure}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=\textwidth]{figures/ml_pedagogy/fig_embedding_separability.pdf}
    \caption{An embedding turns a non-linearly separable problem into a linearly
    separable one. (a) In the input plane, signal lies within a radius $R$ of the
    origin and background outside it, and no straight line divides the two
    classes. (b) The map $\phi(\mathbf{x}) = [x_1,\,x_2,\,x_1^2 + x_2^2]$ lifts
    the points onto a paraboloid, where the single flat plane $h_3 = R^2$ (grey)
    separates signal from background.}
    \label{fig:embedding-separability}
\end{figure}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.7\textwidth]{figures/ml_pedagogy/fig_activation_functions.pdf}
    \caption{The pointwise activation functions used in the model. ReLU and its
    smooth counterpart GELU drive the feed-forward blocks, and the sigmoid
    squashes a score into a per-hit probability. ReLU has a hard corner at the
    origin and is unbounded above; GELU dips slightly negative before rising to
    meet it; the sigmoid saturates to $0$ and $1$, where its gradient vanishes.}
    \label{fig:activations}
\end{figure}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=\textwidth]{figures/ml_pedagogy/fig_attention_affinity.pdf}
    \caption{A worked example of the self-attention operation on three hits with
    small, illustrative query, key, and value vectors; it shows what the operation
    computes, not a result learned by the trained model. From left to right, the
    queries and keys give the scaled scores $\mathbf{Q}\mathbf{K}^{T}/\sqrt{d_k}$;
    a row-wise softmax turns each row into weights that sum to one; and each hit's
    output is the weighted sum of the value vectors, $\sum_j A_{ij}\mathbf{v}_j$.
    Hits 1 and 2 have aligned queries and keys, so they attend to each other and
    their outputs blend, while hit 3 is different, attends to itself, and is left
    essentially unchanged. This re-expression of each hit as a weighted average of
    the others, before it reaches the next weight matrix, is the core of the
    operation.}
    \label{fig:attention}
\end{figure}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.8\textwidth]{figures/ml_pedagogy/fig_gradient_stability.pdf}
    \caption{Gradient magnitude reaching each layer during backpropagation, for a
    forty-layer stack. The gradient at a layer is the product of the local
    derivatives of every layer above it. When those factors average below one the
    gradient vanishes toward the input; above one it explodes; normalization and
    residual connections hold the factor near one, keeping the gradient order-one
    all the way back.}
    \label{fig:gradient-stability}
\end{figure}
```
